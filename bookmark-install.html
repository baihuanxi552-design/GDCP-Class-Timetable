安装解析书签

只需设置一次。以后登录教务首页，点击书签即可将课程带回课表网站。

拖进书签栏，就装好了

  1. 显示浏览器书签栏（Windows 通常按 Ctrl + Shift + B）。
  2. 将下面的蓝色按钮拖到书签栏，不要直接点击。
  3. 登录教务系统首页，再点击书签栏里的“导入个人课表”。
导入个人课表 ↗ 拖到书签栏

解析成功后自动返回网站，核对校区并保存，无需下载和上传文件。

收藏此页，再替换书签网址

  1. 在浏览器菜单中收藏当前页面，名称填写“导入个人课表”。
  2. 点击下方“复制解析代码”。
  3. 进入书签管理，编辑刚才的书签，将原网址全部替换为复制的代码并保存。
  4. 登录教务首页，从书签列表点击“导入个人课表”。

如果浏览器去掉了代码开头的 javascript:，请手动补上。部分手机浏览器不支持执行解析书签，可改用电脑解析或文件导入。

复制失败？手动选择代码

若书签不生效，请更换浏览器尝试。
