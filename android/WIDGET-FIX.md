# 安卓小部件修复 3.2.14

小部件 Provider 和刷新 Receiver 改为运行在应用默认进程，复用个人课表相同的 SharedPreferences 实例；移除不可靠的 MODE_MULTI_PROCESS。数据键和备份格式保持不变。

设置页改为独立点击选项，使用系统单选对话框选择样式与今天/明天，确认保存后刷新桌面全部小部件。替换依赖弹层宿主的 SuperDropdown。

覆盖安装后若桌面仍保留旧内容，点击小部件刷新，或移除并重新添加小部件。无手机连接，本次不声称已通过真实启动器测试。

## 3.2.15 桌面空白兼容修复

小部件使用单一 RemoteViews 布局，按桌面提供的尺寸选用紧凑/宽/总览样式。每次完整更新显式重置内容、标题、课程列表及底部区域的可见状态；切换今天/明天和尺寸时不再依赖桌面多布局容器缓存。保留上次的数据进程修复。实际启动器效果仍待用户确认。

## 3.2.16 自适应精简

小尺寸保留下一节和时间，足够时显示简写教室；中尺寸优先课程名和时间；大尺寸补充教室与教师。按字体缩放、宽度和实际文本高度确定可显示条数，空间不够时降级精简信息，底部提示剩余条数。继续使用单布局更新以保留桌面兼容性。

教室独立显示，长教室文字使用原生 ViewFlipper 横向分段轮播（停留3.5秒，滑动450毫秒），完整保留教室原文与无障碍描述。短文字只有一个子页，保持静止。空间不足时隐藏教室而保留时间；不使用 RemoteViews 不支持的 setSelected 反射来强制跑马灯。

## 3.2.17 完整信息与跨日

时间与教室分区显示。小尺寸按剩余高度将教室分多行展示，过长内容分段滑动，不省略教室。极小尺寸循环展示完整课程名、时间、教室。列表空间不足先移除教师；不足以放一个完整课程时回退单课程布局。当今天有课且最后一节已结束，自动展示明日课表；无课日保留今日空状态。

Release、单元测试及 lint 检查；桌面真机布局与轮播效果待用户验证。

## 3.2.18 统一完整卡片与实际测量

所有尺寸共用纵向课程卡片，课程名、时间、教室位于同一彩色容器。使用 RemoteViews.apply 后 Android 原生控件的实际测量高度判断是否容纳；不再按宽度强制单课程，也不再以估算的单条高度截断课程数量。先隐藏全部可选教师，随后让超长教室分段轮播，再减少课程数量。极小尺寸保留彩色容器并循环展示课程名、时间、教室。

Robolectric Android 35 原生图形测试覆盖 9 种宽度 × 8 种高度 × 3 种字体缩放（216 组），检查布局高度、教室原文保留、课程卡片包含关系，以及宽高／窄高三课程布局；另有超长教室与代表尺寸绘图测试。此为自动化 Android 控件测试，小米桌面真机效果仍需验证。

## 3.2.19

删除小部件配置 Activity、三点入口及桌面重新配置声明。添加直接显示课程，样式自动按品牌选择，今天全部课程结束后自动显示明日。旧小部件手动日期和样式选项不再参与渲染。

## 3.2.20 日期选择设置

小部件三点入口和桌面重新配置入口打开 Miuix 日期设置页。仅提供今天、明天及具体日期，不添加其他设置。每个小部件独立保存日期；取消和系统返回不保存，删除小部件时清除其日期偏好。今天保留课程全部结束后显示明日的行为，明天每天相对北京时间递进，具体日期固定并展示当天全部课程（不因当前时间过滤）。旧小部件默认为今天。

自动测试覆盖跨年／午夜、固定日期、独立保存及删除、取消与重建页面、学期外提示、既有 216 组布局和字体组合。Miuix 页面测试运行需要 Java 21；安卓构建目标保持 Java 17。小米桌面真机设置操作及视觉效果待验证。
