# Android 前台课表刷新（3.2.6）

在「关于 → 设置 → 教务系统」开启「自动更新课表」，并在学校官方页面登录、解析、确认保存。开关默认关闭；首次登录页也提供同一开关。启用后，回到应用前台且距上次尝试至少一小时才检查全部教学周。设置中的「立即刷新课表」不受间隔限制。

刷新只使用现有个人课表解析器和学校 HTTPS 同源页面，不保存密码，不自动填写登录表单，不添加后台周期任务。当前仍只支持 2026-2027-1、1—20 周。

## 会话

Cookie 快照使用 Android Keystore 中的 AES 密钥以 AES-GCM 加密，写入 noBackupFilesDir 的 AtomicFile。快照不进入 JSON 备份。每次 WebView 使用前先清理原生 Cookie，再恢复加密快照；正常结束时清理原生 Cookie、缓存和 WebStorage。运行期间 WebView 仍由 Android 管理临时浏览数据；会话快照不等于永久有效的学校登录。校方使会话过期后需重新登录。

同一时刻只允许一个教务 WebView，会话恢复完成后才加载学校页面。关闭开关会使在途请求失效，删除加密快照；恢复备份或上一份课表会关闭自动更新，避免立刻覆盖恢复结果。应用系统备份保持关闭。

## 数据保护

- 请求限于学校 HTTPS 主机；证书错误直接失败，不忽略证书校验。
- 刷新在前台运行，离开 Activity 时取消；网络失败、登录过期、空数据、学期不匹配、解析失败均不替换原课表。
- 比较规范化的课程时段，忽略行顺序、重复行和周次顺序。常规变化自动保存；全部旧时段被替换，或至少 3 个旧时段且超过 30% 被移除时，先显示变化供确认。
- 待确认结果超过 24 小时或本机课表已变化时作废；保存前再次检查开关代次、个人课表启用状态和原始快照，防止旧请求覆盖新数据。
- 每次替换保存上一份个人教务课表；自建课程按既有独立来源保留。成功保存后重载课程并刷新桌面小部件。
- JSON 备份新增可选 personalImport / personalImportActive 字段，兼容旧 v1 备份。旧备份缺少这些字段时不覆盖本机个人导入数据。会话凭据永不导出。

## 验证

JUnit 覆盖规范化比较、教室变化、删课确认阈值、拒绝空表/错误学期，以及自动/手动刷新资格和限频。独立 Android 模拟器测试验证 Keystore 加密快照、Cookie 恢复、篡改拒绝、关闭删除和单会话互斥。

自动检查不能代替学校真实页面和设备验收：仍需验证学校会话有效期、实际页面加载、完整周次解析、调课结果，以及不同厂商 WebView 的兼容性。没有在测试中使用真实账号、凭据或个人课表。
