# 个人教务课表自动更新方案（待实现）

本次只修复应用内课程配色和周视图尺寸。以下为自动同步设计，不代表已经启用后台更新。

## 现有接入基础

- `JwImportActivity.java` 使用学校官方 WebView 登录；退出会清除 Cookie、WebStorage 和缓存，因此当前不会保留可供定时任务使用的会话。
- `app/src/main/assets/jw-parser.js` 的 `collect()` 已使用同源 GET 请求个人首页的全部周课表：
  `https://jw.gdcp.edu.cn/jsxsd/framework/mainV_index_loadkb.htmlx?rq=all&sjmsValue=<页面节次模式>&xnxqid=<学期>&xswk=false`。
  响应为 HTML，依赖登录 Cookie；节次模式从页面读取，不能硬编码。这里是对仓库代码的核查，本次没有重新登录学校验证接口或会话有效期。
- 解析器支持个人首页详情和个人课表页，输出 `gdcp-personal-timetable` JSON；当前限定学期 2026-2027-1、1—20 周，并拒绝空结果。
- `PersonalImport` 保存 `jwPersonal`，与自建课程分别存储；现有 `BackupData` 没有导出/恢复这一字段，自动更新前需要扩展备份格式。

## 第一阶段：打开应用自动检查 + 手动刷新

1. 提供可关闭的“自动更新”设置。开启时解释需在本机保留登录会话；关闭/退出账号时清理会话并取消同步任务。不保存账号密码，不上传课表或会话到 GitHub、服务器或日志。需要给后台 HTTP 客户端使用的会话凭据以 Android Keystore 密钥加密存于应用私有目录，排除系统备份。
2. 首次在官方页面登录，读取真实学期、节次模式，再调用现有全部周接口。将学期和校历从固定常量改为经过确认的配置，跨学期不直接覆盖旧学期。
3. 应用回前台、距离上次成功检查超过 1 小时时刷新；提供“立即更新”和最后成功时间。复用现有 WebView/解析器完成第一阶段；会话失效时显示“需要重新登录”，保留旧课表。刷新期间仍可查看缓存。
4. 校验最终响应来源、重定向、登录页特征、学期和完整解析结果；HTTP 200 不等于成功。禁止把登录页、局部周课表或解析失败当作删课。空结果和大规模删除先要求用户确认。
5. 对规范化结果计算内容摘要；有变化时生成新增、删除、时间/教室/老师变更摘要。上游存在稳定课程/教学班 ID 则保留；缺少 ID 时保留原始记录并用保守匹配，无法可靠识别的移动显示为删除+新增，不用课程名称单独当主键。
6. 保存上一份有效快照，在同一次原子更新中替换教务来源数据、更新时间和变更摘要；保留本机自建课程及其设置。通过单一同步任务与账号/学期版本校验避免旧请求覆盖新账号数据。成功后刷新界面、小部件和相关提醒。
7. 扩展可导入备份以包含个人课表快照、学期和自建课程，兼容旧备份；不包含 Cookie 或密码。支持查看变更和恢复上一版本。

## 第二阶段：后台检查

验证该学校接口可用持久会话直接 HTTP 拉取后，使用 WorkManager 唯一周期任务，每 6 小时尝试一次，要求网络可用，失败采用退避。解析在工作线程中执行；DOM 解析需移植到可后台运行的解析器并通过同一批脱敏夹具验证，不能直接在 Worker 中假设存在 WebView DOM。

WorkManager 受 Android 省电策略影响，不能保证准点，也不能保证教务系统一改就收到。后台会话过期则暂停自动拉取、提示重新登录；不自动填写密码或绕过验证码。若学校不支持长期会话，则保留第一阶段的自动检查/重新登录流程，不承诺永久免登录。

- [jlu-mobile-schedule 河海大学强智适配器](https://github.com/con9uer666/jlu-mobile-schedule/blob/39f2b96d3ec73ab07c42c4e8c3b4e8359e8831bc/lib/data/providers/hhu_jsxsd.dart)：参考同源 fetch + HTML 解析的接入方式。其他学校的 `xskb_list.do` 不能当作本校已验证接口；本次没有复制其实现。

## 本次 UI 修复的验收

- 今天、日视图、周视图对同一日期使用一致的配色；13 门以内无重复，超过调色板容量均衡复用；同名的不同上课时段也分配不同颜色。
- 每次显示某一周，按该周最高课程卡片统一所有卡片高度；宽度按当前网格列宽统一。空格保留至少 96dp；同一时段多门课程仍各自显示，避免把叠加总高度误当成单张卡片高度。
- 测量使用普通 Text，不为不可见测量内容注册动画图层。实际显示保留原有文字动画。
- 真机需检查长课程名/教室、不同字体缩放、空周、切换周、横屏及同一时段多门课程；CI 编译和单元测试不能替代这些视觉验收。
