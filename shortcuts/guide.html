快捷指令版安装说明

v1 · 离线查询＋课程日历。源文件未签名，苹果设备运行尚未验证。

先准备查询数据

  1. 在配置页面选择课表、校区和所有分组选课，下载 GDCP-Class-Timetable.json。
  2. 在“文件”App 中放到 iCloud Drive → Shortcuts。如文件名带有“(1)”等后缀，改回上述固定名称。
  3. 让文件保留本地下载状态。日常查询不访问网站；更换课表或调整课程时重新导出并替换文件。

配置页面中的选择只是导出设置，不会自动同步到已下载 JSON。

没有 Mac：在设备上搭建

在“快捷指令”中创建“个人课表”。以下中文动作名称可能随系统版本略有变化；括号为英文名称。所有变量均需点击输入位置选择对应动作的输出，不能输入变量名称作为普通文字。

共同准备动作

顺序／动作设置与输出
1 · 从文件夹获取文件
Get File from Folder		文件夹选 iCloud Drive/Shortcuts；路径 GDCP-Class-Timetable.json。关闭“找不到时出错”（如系统提供）。保存输出为“课表文件”。若该版本不支持关闭错误，缺失文件会由系统报错，重新下载即可。
2 · 如果课表文件有任何值有文件：继续后续动作；否则：显示“未找到课表文件，请重新下载并确认文件位置”，停止快捷指令。
3 · 获取文本／从输入获取字典获取“课表文件”的文本，再把文本转换为字典，命名“课表字典”。读取 format，确认等于 gdcp-shortcuts-timetable；不匹配时显示“数据格式错误”并停止。
4 · 日期（当前日期）命名“当前日期”，只在运行开始获取一次。
5 · 日期（指定日期）输入 2026-08-31T00:00:00+08:00，命名“学期起点”。
6 · 获取日期之间的时间从“学期起点”到“当前日期”，单位“秒”，命名“经过秒数”。此算法按绝对时间计算，不依赖手机所在时区。
7 · 获取字典值在“课表字典”读取 outside，命名“学期外提示”。
8 · 从菜单中选取菜单项：今日课程、明日课程、下一节课、本周课程。按下面分别添加动作。

今日／明日／本周分支

  1. “计算表达式”：今日和本周使用 floor(经过秒数 / 86400)；明日使用 floor((经过秒数 + 86400) / 86400)。“经过秒数”插入变量，输出命名“日序号”。
  2. 从“课表字典”获取 daily（今日、明日）或 weekly（本周），命名“查询表”。
  3. 从“查询表”获取键为“日序号”的字典值；将日序号作为文本键使用，必须为整数、不能加千位分隔符。命名“查询结果”。
  4. 如果“查询结果”有任何值：显示结果；否则：显示“学期外提示”。结束此菜单分支。

下一节课分支

  1. 如果“经过秒数”小于 0，或大于等于 12096000：显示“学期外提示”，停止快捷指令。
  2. 从“课表字典”读取 nextIntervals，添加“重复每一项”。
  3. 在重复内，从“重复项目”获取 before（数字）。
  4. 如果 before 大于“经过秒数”：从同一个“重复项目”获取 text，显示结果，然后停止快捷指令。必须停止，否则会显示多条结果。
  5. 结束条件和重复。若没有匹配，显示“学期外提示”。

查询数据已经处理正在上课、下一次开课、跨日及并行课程。按列表顺序选择第一个 before 大于当前经过秒数的项即可，不要自行重新排序。

桌面按钮

主快捷指令搭建好后可添加到主屏幕，也可放入“快捷指令”小组件。若要独立的“今日课表／明日课表／下一节课／本周课表”按钮，复制主指令，删除菜单并只保留对应分支；共同准备动作保留。小组件展示名称和图标，点击后展示查询结果，结果不会常驻小组件。

将来有 Mac：签名导入

下载完整源码包，解压后在 Mac 的终端中进入文件夹。使用苹果自带命令：

shortcuts sign --mode anyone --input Class-Timetable.unsigned.shortcut --output Class-Timetable.shortcut

同样签名 Today、Tomorrow、Next、Week 文件可获得四个独立按钮。签名会将快捷指令送交苹果验证；源文件不内嵌个人课表。文件动作的文件夹引用可能需要在编辑器中重新选择 iCloud Drive/Shortcuts。源文件的结构已自动检查，但尚未通过苹果签名及导入验证。

苹果官方签名说明

系统日历与提醒

  1. 下载配置页面生成的 GDCP-Class-Timetable.ics。每个课程时段是一条独立事件，提前十分钟提醒。
  2. 为课程建立独立日历，名称例如“个人课表 2026 秋”。导入时选这个日历，避免混入个人日程。
  3. iPhone／iPad 是否能直接从文件打开并批量导入，需在实际系统版本验证。若无法导入，可通过 Mac 日历导入并同步；本版不声称任意 iOS 版本都支持从“文件”直接导入。
  4. 添加系统日历小组件查看接下来的课程。显示样式由系统决定。

不要重复导入。更新课表时先删除原课程专用日历中的旧事件，再导入新版；不要删除个人日历。事件 UID 保持稳定，但不同导入工具不一定自动去重。ICS 没有建立在线订阅，不会自动更新。快捷指令不会自动写入或删除日历。

验证状态与数据说明

数据核对：2026-10-02。学期第一周从 2026-08-31 开始，20 周，按北京时间计算。换课、教室和周次按现有数据展开；体育项目依据其他课表教师记录补全时保留提示。

自动检查和测试详情见 验收记录。苹果签名、真实设备查询、iCloud 文件读取、离线状态和日历导入均待实机验证。没有安装成功的 iCloud 快捷指令链接。

JSON 格式为 gdcp-shortcuts-timetable，版本 1。events 保存完整事件；daily/weekly 的键是相对学期起点的日序号；nextIntervals 按 before 递增排列，before 为相对学期起点的秒数，text 是对应时间区间的查询结果。此专用 JSON 不是网页／安卓备份，不能反向导入它们。

最新调整以教务系统为准。页面不连接教务系统。
